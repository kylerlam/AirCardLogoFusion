# 八達通 Octopus · 背景融色样例

背景参考图由用户提供。预览只裁去外部白边和卡框；`background-reference.png` 保留原附件，不是重新制作的背景上传图。

- 卡面裁取区域：原图 `(29, 14, 1529, 960)`；卡面约 1.586 : 1。
- 占比主色：深蓝黑、灰粉、米白，另有亮蓝光泽。原样取深色会让左上角字样继续难读。
- 推荐 `upload-fusion.svg`：从灰粉、近白和蓝色取色相，提亮为 `#FFC2DD → #FFF9FC → #8DD3FF`。只替换原标识的填充颜色，不改字形、Logo 造型或原有笔画样式。
- `upload-fusion-vivid.svg` 和 `upload-fusion-soft-plate.svg` 为此前的效果对比稿，带有额外描边或底衬，不是本次只换色的交付版。
- 参考背景本身已有旧的深色「八達通 Octopus」字样；本样例叠加位置接近，但若换用无字背景会更干净。

`fusion-master.svg` 采用 85.60 × 53.98 mm、等比矢量画布；`upload-fusion*.svg` 是针对当前 AirCard 网页的固有尺寸适配版，仍是纯 SVG 矢量文件，不经 PNG 转换。
