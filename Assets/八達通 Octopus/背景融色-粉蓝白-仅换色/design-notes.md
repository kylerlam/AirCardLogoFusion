# 八達通 Octopus · 粉蓝白仅换色方案

输入：原始透明矢量标识 `../foreground.svg`；背景参考图沿用此前用户提供的卡面。参考图含白边和已烙入的旧深色字样，仅在预览和取色时裁去外框，未修改背景图片。

- 卡面裁取区域：原图 `(29, 14, 1529, 960)`，约 1.586:1。
- 背景主色是深蓝黑、灰粉、米白，另有蓝色光泽。Logo 所在区域亮度中位数为 `0.0139`，第 90 百分位为 `0.0721`。
- 正式版 `upload-fusion.svg` 沿用用户选定的粉→近白→浅蓝 `#FFC2DD → #FFF9FC → #8DD3FF`。三端颜色对该区域第 90 百分位亮度的对比比值约为 `5.74:1`、`8.28:1`、`5.28:1`。
- `upload-fusion-readable.svg` 是仅换色的浅色对比版：`#FFE0EE → #FFFFFF → #BCE6FF`。视觉预览中它更亮，正式版仍使用用户指定的配色。
- 两版只更改原路径的 `fill`；没有改文字、字形路径、Logo 造型、位置、透明度，也没有新增描边、底衬或滤镜。

`fusion-master.svg` 保留原件 `85.60 × 53.98 mm` 固有尺寸；`upload-fusion.svg` 是 AirCard 上传所需的 `1536 × 969` 固有尺寸。两者都是透明矢量 SVG。`preview.html` 和 `preview.png` 展示两版与参考背景的叠加；参考背景中原有的深色字样可能在叠加后形成重影，正式使用宜选无字背景。
